## Task overview
- **B1:** Backtracking graph colouring with search instrumentation and two vertex-ordering strategies.
- **B2:** Same-size easy and difficult graph instances to compare search effort.
- **B3:** Exact minimum set cover compared with a greedy approximation, including a counterexample.
- **B4:** Next-Fit bin packing, server allocation output, and a non-optimal challenge input.

The `sample_output.txt` files contain reproducible console output from the included source programs.
